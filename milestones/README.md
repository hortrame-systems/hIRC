# hIRC milestone checkpoints

Each milestone report is cumulative and links exact detailed artifacts. Starting
with Milestone 02D, closure requires validation, Git commit and branch push under
the [milestone protocol](../drafts/hirc_milestone_git_protocol_v0_1-draft.md).

Earlier milestones were recorded in `review/` but were not individually pushed;
Milestone 02D is the explicit catch-up Git checkpoint.
